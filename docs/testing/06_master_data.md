# Data Master — Kasus Uji

## Ikhtisar

Modul ini mencakup data master/referensi yang dikelola di backend Duta Residence dan diekspos melalui aplikasi web React Admin: **Cluster** (`clusters.view` / `clusters.create` / `clusters.update-rate` / `clusters.delete`), **Jadwal Tarif Cluster** (Cluster Rate Schedules) yang bersarang di bawah sebuah cluster (diatur oleh `clusters.view` untuk pembacaan dan `clusters.update-rate` untuk semua mutasi), **Jenis Komponen Peta Cluster** (Cluster Map Component Types) — katalog ikon/bentuk yang digunakan oleh palet komponen pada editor peta cluster (`cluster-map-components.manage` untuk mutasi, `cluster-maps.view` untuk pembacaan), dan endpoint **Lookup** yang bersifat baca-saja (`lookup/regencies`, `lookup/districts`, `lookup/roles`) yang digunakan untuk mengisi dropdown di seluruh aplikasi. Semua endpoint berada di bawah `api/v1`, merespons melalui envelope `ApiResponse` standar, dan minimal memerlukan `auth:sanctum`.

Data bergaya referensi lain yang disebutkan dalam sistem yang lebih luas — **jenis properti** (property types), **status okupansi** (occupancy statuses), dan **status penghuni** (resident statuses) (dirujuk oleh `Unit` melalui `property_type_id` / `occupancy_id` / `status_id`) serta **status tagihan** (billing statuses) (dirujuk oleh `Billing` melalui `status_id`) — merupakan tabel lookup tetap yang sudah diisi (seeded) dan **tidak memiliki controller CRUD atau endpoint API khusus** di dalam basis kode. Data-data ini tidak dapat diuji secara independen melalui UI atau API dalam modul ini; tidak ada kasus uji yang dibuat terhadap endpoint yang direka-reka untuk data tersebut. Cakupan pengujian atas nilai-nilai ini terjadi secara tidak langsung, sebagai opsi yang dapat dipilih di dalam formulir Unit/Billing pada modul lain.
