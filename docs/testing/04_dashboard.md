# Dashboard — Kasus Uji Black-Box

Dokumen ini membahas empat pengalaman dashboard di Duta Residence: Dashboard Admin/Staf internal (web), Dashboard Portal Penghuni (web dan Android), Dashboard Supervisor (web dan Android), dan Dashboard Kolektor (Android). Untuk setiap dashboard, rangkaian pengujian ini menguji pemuatan awal/status loading, tampilan data kosong, perilaku refresh/reload, navigasi dari widget/pintasan ke layar detail, perbedaan konten berdasarkan peran, dan — khusus untuk web — tata letak responsif. Sebuah diskrepansi pelabelan data yang sudah diketahui pada Admin Dashboard (kartu "Total Penghuni" sebenarnya menampilkan jumlah Unit, bukan jumlah Penghuni) didokumentasikan sebagai pengujian perilaku-saat-ini yang khusus, bukan diasumsikan sudah diperbaiki.
