# Log Audit — Kasus Uji Black-Box

Dokumen ini membahas jejak audit (audit trail) Duta Residence: daftar log audit yang dilindungi izin `audit-logs.view` (backend `GET audit-logs` dan halaman web `AuditLogsPage`), apa yang sebenarnya ditangkap oleh middleware global `audit` untuk setiap permintaan yang bersifat mutasi data, perilaku filtering/pencarian/paginasi pada daftar tersebut, log aktivitas per pengguna yang ditampilkan pada `GET users/{user}/activities` dan tab Activity Log pada halaman Detail Pengguna, serta kontrol akses untuk pengguna yang tidak memiliki izin `audit-logs.view`. Jejak audit dirancang bersifat append-only (tidak ada rute untuk mengedit/menghapus), dan satu panggilan API yang bersifat mutasi dapat menghasilkan dua baris log terpisah — entri generik `{method}_request` dari middleware ditambah entri eksplisit bernama-bisnis dari controller/service — keduanya diuji di bawah ini.
